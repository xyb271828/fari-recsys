# Fari RecSys

An activity recommender using synthetic interactions and a separate MovieLens-1M benchmark. The pipeline compares popularity and collaborative-filtering baselines with two-tower retrieval, and applies LightGBM ranking and MMR in the synthetic activity experiment. A FastAPI service exposes FAISS HNSW retrieval with a popularity fallback.

| Result | Measured comparison |
| --- | --- |
| Synthetic activity Recall@100 | 54.88% with the logQ two-tower model and 56.61% with global popularity |
| Synthetic activity long-tail Recall@100 | 42.46% with the logQ model and 26.88% with global popularity |
| Native candidate service | 50 achieved QPS, zero failures, and HTTP p99 of 33 ms with stage timing and 46 ms in the control run |

## Run locally

Use Python 3.11. From this repository's root:

```sh
python -m pip install -e '.[recsys,dev]'
python -m pytest -q

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  python -m recsys.production --output runs/fari
```

The last command rebuilds the index, user vectors, and popularity list using synthetic inputs. It also writes the ranking results to `runs/fari/ranking.json`.

## Run the Docker latency benchmark

Start Docker Engine. On macOS, open Docker Desktop and confirm `docker info` shows the Server section.

```sh
bash services/candidate_service/profile_docker.sh runs/fari runs/fari-docker-profile
```

The script builds the candidate image and runs two 45-second Locust experiments at a target of 50 QPS. Read `runs/fari-docker-profile/control.json` and `runs/fari-docker-profile/profile.json` for the results. The included latency results come from native Uvicorn runs. Docker measurements are pending.
